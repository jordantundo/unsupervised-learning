# Unsupervised Learning: Clustering & Dimensionality Reduction

This repository demonstrates **K-Means clustering** and **PCA** using `scikit-learn`.

## 📌 Projects
1. **Clustering**
   - K-Means on Iris Dataset (`kmeans_iris.py`)
   - Customer Segmentation (`kmeans_customer_segmentation.ipynb`)
2. **Dimensionality Reduction**
   - PCA on Iris Dataset (`pca_iris.py`)
   - PCA for MNIST Digit Visualization (`pca_mnist.ipynb`)
